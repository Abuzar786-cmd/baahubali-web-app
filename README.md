A full-stack, interactive web application designed to manage strategy, warrior registries, and custom audio tracks for the Mahishmati War Room. Built with Python and Flask, utilizing JSON-backed persistent data structures, and hosted live on production servers via Render.

🌐 **Live Web Application:** [https://mahishmati-war-room.onrender.com](https://mahishmati-war-room.onrender.com)

---

## ✨ Features

- 🛡️ **Warrior Registry (CRUD):** Full capability to add, update, and manage army rosters dynamically.
- 🎵 **Interactive Audio Player:** Custom media player integration for tactical audio and battle theme playback.
- 📁 **Media & File Handling:** Support for uploading custom MP3 audio files and serving dynamic assets via Flask static routing.
- ⚡ **Production WSGI Deployment:** Deployed on Render using Gunicorn as a high-performance HTTP server gateway interface.

---

## 🛠️ Tech Stack & Architecture

- **Backend Framework:** Python / Flask
- **WSGI Server:** Gunicorn
- **Frontend:** HTML5, CSS3, JavaScript
- **Data Persistence:** JSON (`mahishmati_data.json`)
- **Deployment Platform:** Render
- **Version Control:** Git / GitHub
